# Commit attribution

Every commit created or amended by a coding agent in this repository must
include Codex as a co-author. Add the following trailer to the commit message:

```text
Co-authored-by: Codex <noreply@openai.com>
```

Preserve the human author's identity. Do not replace the author or committer
with Codex; attribute Codex through the co-author trailer. Include the trailer
exactly once and preserve it when amending a commit.
